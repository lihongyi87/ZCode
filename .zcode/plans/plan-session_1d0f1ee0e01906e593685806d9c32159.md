# DSH DeepSeek 专属能力吸收(spec 150)

## 结论先行(探索后的诚实修正)

- **repeat-tool-reminder 守卫**:ZCode **已存在同构实现**(`model-anomaly.ts` 的 `detectRepeatedToolCallWarnings`,阈值 3、advisory、`model_anomaly` 通道)——不做移植,只补 streak 检测的单测空白。
- **DeepSeek 适配真实缺口**:官方内置模板走 `anthropic-messages + api.deepseek.com/anthropic`(缓存映射全通);但**自建 `openai-chat-completions` provider 指向 api.deepseek.com 时,DeepSeek 原生 `prompt_cache_hit_tokens/prompt_cache_miss_tokens` 顶层字段无映射**——缓存命中显示 0。这是本批唯一的行为修复。
- **`dsh_session_log` 明确不吸收**:字段绑定 DSH 私有 canonical 会话格式 v1(开发者预览、随时破坏兼容),服务端效果未见于公开 API 文档;格式耦合风险 > 收益。登记拒绝理由与重启条件(官方公开文档化该协议且格式稳定)。
